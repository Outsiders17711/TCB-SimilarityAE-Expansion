# TCB SimilarityAE Expansion (TSAE) Webapp

This is a Streamlit webapp companion to the framework presented in the TSAE conference paper. It is designed to be a standalone application that can be deployed independently of the main TCB repository, with all necessary code and data self-contained. The app allows users to interactively explore the station allocation results generated by the framework based on different data/parameter configurations as explored in the paper.
